## 🚀 Featured Work

### 🧠 Student Health Risk Prediction
**Machine Learning • CatBoost • scikit-learn • Python**

End-to-end multiclass machine-learning project developed for Kaggle's Playground Series, working with more than **690,000 training records** and a heavily imbalanced target.

- Compared Decision Trees, HistGradientBoosting, Random Forest, and CatBoost
- Applied stratified validation and class-imbalance handling
- Achieved **0.9497 balanced accuracy** on local holdout data
- Achieved **0.94922** on the Kaggle public leaderboard

[View Repository](https://github.com/Rodger-CZ/student-health-risk-prediction)
